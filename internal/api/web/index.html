    关于 FnCluster

    FnCluster 把多台飞牛组成一个统一环境：节点状态、存储统计、应用目录和远端桌面。节点间使用 mTLS，集群身份独立于飞牛账号。

    应用与面板目录来自自动发现。所有集群操作写入审计日志。

    高级 / 调试

    重置节点身份会删除本机的集群状态与节点 ID，其他节点的数据不受影响。
