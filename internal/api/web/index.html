    关于 FnCluster

    FnCluster 把多台 fnOS 组织成一个可统一查看的环境：节点健康、存储统计、应用目录与远端桌面。集群身份独立于 fnOS 用户身份，节点之间使用 mTLS。

    安全边界：本地网关登录 + 集群 mTLS；中继只拨本机回环与已声明端口；所有集群操作写入审计日志。

    高级 / 调试

    重置节点身份会删除本机的集群状态与节点 ID，用于节点被移除后卡住或调试。创建者上仍保留旧成员记录，需要在那里移除；其他节点的数据和存储不受影响。
